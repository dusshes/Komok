# Каталог и бронирование

## Зачем

Покупатель находит товар нужного магазина и резервирует его для визита в магазин.

Правила создания и управления категориями приведены в [документе о категориях](categories.md).

## Сценарии пользователя

- Покупатель выбирает магазин фильтром каталога.
- Покупатель фильтрует каталог по одной или нескольким категориям товаров.
- Покупатель может включить группировку товаров по категориям.
- Покупатель может искать товары по названию и описанию и выбирать порядок сортировки.
- Покупатель просматривает товары выбранного магазина, видит фотографии товара, его доступность и срок брони.
- В карточке товара описание показывается только первой строкой с многоточием при необходимости; карточка поддерживает карусель фотографий с точками без автоматического перелистывания, кликом по точке и свайпом.
- При клике по карточке вне кнопок и точек карусели открывается подробное окно товара с полным описанием, характеристиками и всеми фотографиями в качественном размере.
- В подробном окне доступного товара покупатель может открыть существующую форму бронирования; для забронированного или проданного товара эта возможность недоступна.
- Покупатель бронирует доступный товар без регистрации, выбирая один доступный слот с датой и временем прибытия и указывая обязательное имя и контакт в одном мессенджере.
- В форме бронирования покупатель видит адрес осмотра товара; в каталоге адрес магазина не показывается.
- После фактической продажи администратор отмечает товар как проданный.

## Правила

- Каждый товар принадлежит одному магазину.
- Каждый товар в каталоге показывается с назначенной ему категорией.
- В карточке товара показывается облегчённое изображение для быстрой загрузки; если фотографий несколько, покупатель может переключать их точками или свайпом. В каталог попадают фотографии после перевода товара в статус «На продаже».
- Для фотографий генерируются три размера: thumbnail для карточки каталога, medium для карусели и original для подробного окна. Подробное окно загружает качественные фотографии только при открытии.
- Подробное окно закрывается крестиком, кликом вне окна или клавишей Esc. Автоматического перелистывания фотографий нет.
- Форма бронирования в подробном окне использует выбор доступного слота, обязательное имя, мессенджер и контакт для связи.
- Характеристики в подробном окне включают название, магазин, категорию, цену, статус доступности и полное описание.
- Покупатель может выбрать несколько категорий; каталог показывает товары, относящиеся хотя бы к одной из них. Если категория не выбрана, показываются товары всех категорий.
- Неактивная категория остаётся доступной в фильтре, пока в каталоге есть относящиеся к ней товары.
- Группировка по категориям включена по умолчанию; покупатель может отключить её. Группы упорядочены по названию категории; внутри групп сохраняется выбранная сортировка товаров.
- Сортировка по умолчанию — по новизне, от новых товаров к старым. Новизна определяется временем появления товара в каталоге после приёма магазином. Также доступны сортировки по названию от А до Я, цене по возрастанию и цене по убыванию; при одинаковой цене товары упорядочиваются по названию от А до Я.
- Поиск находит введённую последовательность символов в названии или описании без учёта регистра. Поиск применяется одновременно с фильтрами магазина и категорий.
- Для бронирования регистрация не нужна. Покупатель выбирает один слот с датой и временем, указывает обязательное имя, мессенджер и контакт для связи; телефон и email в форме не запрашиваются.
- Доступные слоты показываются в одном поле выбора в формате даты и времени. Слоты формируются с шагом 30 минут внутри расписания выбранного магазина, доступны только будущие даты и время до окончания рассчитанной брони. Покупателю не предлагаются времена вне рабочего расписания или позже окончания брони.
- Доступные слоты, время визита и срок окончания брони отображаются с фиксированным UTC-смещением магазина, даже если часовой пояс устройства покупателя отличается.
- В форме бронирования показывается простая фраза с адресом осмотра, например: «Я приеду на осмотр по адресу: {адрес магазина}». Отдельное подтверждение адреса не требуется. Адрес не показывается в каталоге.
- Длительность брони настраивается отдельно для каждого магазина и измеряется в рабочих часах магазина. Отсчёт начинается в момент создания брони; закрытое время не входит в длительность. Время прибытия и расчёт брони используют фиксированное UTC-смещение магазина.
- В одно время у товара может быть только одна действующая бронь. Повторная бронь недоступна, пока действует текущая бронь.
- Отменить или продлить действующую бронь нельзя. По окончании срока система автоматически снимает бронь и возвращает товар в продажу; после этого его можно забронировать снова.
- На витрине у забронированного товара отображается время окончания брони.
- Онлайн-оформления покупки и оплаты покупателем нет. После фактической продажи администратор устанавливает товару статус «Продано».

## Ошибки и крайние случаи

- Нельзя забронировать товар, который уже забронирован или продан.
- Нельзя выбрать время прибытия вне расписания магазина, в прошлом или позже рассчитанного окончания брони.
- Если расписание магазина не настроено, бронирование с выбором времени прибытия невозможно.
- После автоматического завершения брони товар снова доступен для бронирования.
- Если фотография отсутствует или не загрузилась, карточка и подробное окно сохраняют работоспособность и показывают нейтральное состояние без изображения.

## Критерии готовности

- Каталог фильтруется по магазину и показывает фотографии товаров, переведённых на продажу.
- Описание в карточке ограничено одной строкой; карусель позволяет переключать фотографии точками и свайпом без автоперелистывания.
- Клик по свободной области карточки открывает подробное окно с полным описанием, характеристиками и качественными фотографиями; окно закрывается крестиком, кликом вне него и клавишей Esc.
- В подробном окне доступного товара покупатель может забронировать его через форму с выбором слота и контактными данными; для недоступного товара кнопка бронирования не показывается.
- Каталог поддерживает мультифильтр категорий, группировку по категориям, включённую по умолчанию и отключаемую покупателем, поиск по названию и описанию и все четыре порядка сортировки.
- При включённой группировке товары распределяются по категориям и сохраняют выбранный порядок сортировки внутри каждой группы.
- Покупатель может забронировать доступный товар без аккаунта, выбрав доступный слот даты и времени и указав обязательное имя, мессенджер с контактом для связи; телефон и email не запрашиваются.
- Адрес магазина отображается простой фразой только в форме бронирования; в каталоге адреса нет.
- Расписание проверяет выбранное время прибытия и отклоняет бронь, если время прибытия позже её окончания. Срок брони отсчитывается от создания и учитывает только рабочие часы магазина.
- Пока бронь активна, повторная бронь невозможна и на витрине виден срок её окончания.
- Бронь нельзя отменить или продлить; после истечения срока товар автоматически возвращается в продажу.
- Администратор может отметить товар как проданный.
