# Текущая работа

Вставьте сюда сырой текст текущей задачи. Его уточнение и формализация выполняются по алгоритму из [workflow.md](workflow.md).

В Комке должно быть доступно:
1. просмотр каталога продаваемых товаров, бронирование товара на определенное время (так чтобы через это время товар сам возвращался в продажу)
2. размещение товаров на комиссию (пользователь должен зарегистрироваться)
3. регистрация пользователя должна быть через подтверждения емайла, и содержать емайл, пароль, подтверждение пароля, способ связи (телега, ватсапп, макс, зало), реквизиты для перевода премии
4. магазинов может быть несколько, к каждому из них привязан админ, один админ может быть привязан к нескольким магазинам
5. админ модерирует размещение товара на комиссию, корректирует описание, цену продажи, процент комиссии (при создании заявки на комиссию, процент комиссии ставится дефолтный, для каждого магазина настраивается своя сетка комиссий в зависимости от цены), админ может устанавливать любой процент
6. после модерации заказ он возвращается к клиенту с уведомлением типа привези товар по такому-то адресу
7. когда товар получен, админ переводит его в статус на продажу
