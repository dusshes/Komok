# Текущая работа

Товар должен относится к какой-то категории.
Категории хранятся в отдельной таблице.
Эта таблица изначально заполнена возможными категориями для товаров сдаваемых в комиссионку.
Суперадмин может добавлять, переименовывать и делать неактивными категории. Неактивная категория убирается из списка доступных при создании товара, но продолжает отображаться в каталоге.
В каталоге сделать мультифильтр по категриям.
В каталоге сделать включение группировки по категориям.
В каталоге сделать сортировку: по алфавиту, по новизне, по цене вверх, по цене вниз.
В каталоге сделать фильтр - поиск. Ищет вхождение в наименование или описание.
