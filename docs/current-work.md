# Текущая работа

Ошибки в формах должны быть понятными и отображаться на самой форме: ошибка конкретного поля — рядом с ним, общая ошибка — сверху формы. Это правило относится ко всем полям, для которых заданы проверки; системные англоязычные тексты пользователю не показываются.

Для ошибок проверки пароля использовать сообщения:

- «Добавьте в пароль специальный символ».
- «Добавьте строчную латинскую букву».
- «Добавьте заглавную латинскую букву».

Реквизиты для выплаты при регистрации необязательны. Их отсутствие не должно блокировать отметку выплаты произведённой.
